计算机视觉：让模型读懂图像

照片里是什么、东西在哪里、哪些像素属于同一个物体，以及怎样从图像认识三维场景，都是视觉研究中的问题。分类、检测、分割和三维视觉需要的输出不同，也形成了不同的数据集、模型和评价方法。

这些任务都涉及怎样从像素中学习有用的表示。卷积网络利用局部结构提取特征，视觉 Transformer 将图像切成小块，用 Attention 组织它们之间的信息。学到的表示可以用于识别和检索，也会成为图文模型与机器人感知的一部分。

研究主题
  • 表示学习：从图像和视频中学习可迁移的特征。
  • 识别与测量：类别、位置、轮廓和属性的预测。
  • 空间与时间：深度、三维结构、运动与事件的建模。

关键概念

卷积 / CNN
让一个小滤镜在图像上移动，同一组参数检查不同位置。多层组合后，可以从局部纹理形成更复杂的特征。
特征 / representation
模型中间层产生的一组数字，用来保留对任务有用的信息。它可以交给分类器，也可以供检测、检索等任务使用。
Patch 与 attention
Patch 是切下来的图像块；Attention 根据输入内容计算块之间的关系，组织信息的交换。
IoU 与 mAP
IoU 衡量预测框与真实框的重叠程度；mAP 汇总各类别的检测表现，其数值与采用的重叠阈值和评价协议有关。

视觉表示与网络结构

从手工设计特征到通过数据学习特征，视觉模型逐渐把图像表示与任务目标一起训练。网络加深后，优化本身也会变得困难。ResNet 引入残差连接，让一组层学习相对输入的改变量，改善深层网络的训练。

网络的结构还决定特征能利用多大范围的信息。卷积中的感受野随层数与运算变化，Distill 的可视化文章具体讨论了这种关系。ViT 用图像块与 Attention 建模，也把视觉研究与序列模型联系起来。

数据、任务与泛化

识别物体的特征可能来自形状、纹理，也可能来自经常一起出现的背景。换到新的拍摄环境、光照或数据来源时，这些关联会变化。数据标注、预训练与表示学习因此和网络结构一样，是视觉研究的重要部分。

静态图片之外，视频还包含动作与时间关系，多视角图像则提供深度、几何与三维结构信息。视觉表示与文字结合形成多模态模型，用于生成模型时参与图像生成与编辑，在具身智能中还要为行动提供环境信息。

课程、项目与资料

CS231n 介绍视觉任务、卷积网络、模型训练与深度学习方法。MNIST 与 YOLO分别是手写数字分类和目标检测项目，数据、代码与教程已有完整介绍。

更多课程和项目见视觉资料目录；SVL、RAIL 等团队的项目涉及视觉、场景理解与机器人学习。模型的运行速度、显存和部署问题见效率与系统。

代表论文

2012 · NIPS 2012

ImageNet Classification with Deep Convolutional Neural Networks

论文原文 ↗

它在解决什么

能否让网络从大量图片里学出识别物体的特征？

核心想法

用多层卷积从像素逐层提取特征，配合 GPU 训练、ReLU 和抑制过拟合的办法。

为什么选这篇

它适合用来认识数据规模、计算和训练方法怎样共同促成进展。

第一遍读哪里

先看网络结构与训练做法，再看分类结果和错误示例。

读完还要问

研究重点是预设类别的图像分类，不能直接回答物体在哪里。

2016 · CVPR 2016

Deep Residual Learning for Image Recognition

论文原文 ↗

它在解决什么

为什么网络加深之后，连训练集也可能学得更差？

核心想法

让一组层学习相对输入的改变量 F(x)，再把输入加回去，得到 x + F(x)。

为什么选这篇

一个容易画清楚的结构变化，配合普通网络与残差网络的对照实验。

第一遍读哪里

先看退化问题和残差模块，再比较不同深度的训练误差。

读完还要问

残差连接改善优化，不保证任意加深都会更准；数据与计算成本仍然重要。

2016 · CVPR 2016

You Only Look Once: Unified, Real-Time Object Detection

论文原文 ↗项目 / 代码 ↗

它在解决什么

怎样在一次网络前向计算中同时预测物体类别和位置？

核心想法

从整张图直接预测一组框及相应分数，把识别和定位放进同一个训练目标。

为什么选这篇

和入门检测 demo 能对上：看得到框，也能分析漏检、误检和速度。

第一遍读哪里

先看检测流程和网格预测方式，再看定位误差的分析。

读完还要问

原版在小物体、密集物体和精确定位上有明显局限；今天名为 YOLO 的工具已有许多结构变化。

2021 · ICLR 2021

An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale

论文原文 ↗项目 / 代码 ↗

它在解决什么

图像分类是否必须依赖卷积这种局部结构？

核心想法

把图像切成小块，转换成向量，再用 Transformer 在块之间交换信息。

为什么选这篇

它把视觉与语言中的序列处理联系起来，也强调预训练数据规模的作用。

第一遍读哪里

先看图像块如何进入网络，再看不同预训练规模的比较。

读完还要问

原论文的强结果依赖大规模预训练，不能据此认为小数据上 Transformer 一定胜过 CNN。
