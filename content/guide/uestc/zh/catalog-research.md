# 科研方法与常用工具

科研经验、方法文章和工具教程放在一起，涵盖文献检索、实验、写作与汇报。方法文章讨论工作中的判断，工具文档提供具体操作与配置。

[返回资料总索引](resources.md)

## 科研入门与研究经验

- **[Why are research skills so seldom taught? — Michael Nielsen](https://michaelnielsen.org/blog/why-are-research-skills-so-seldom-taught-v30/)**

    从物理研究经验出发，讨论研究技能与课堂解题的差别，以及研究者如何形成自己的工作方式。

- **[Advice to a Beginning Graduate Student — Manuel Blum](https://www.cs.cmu.edu/~mblum/research/pdf/grad.html)**

    关于阅读、思考、研究与写作的经验，其中谈到从问题出发、逐步补充背景的 top-down 阅读方式。

- **[The importance of stupidity in scientific research — Martin A. Schwartz](https://web.stanford.edu/~fukamit/schwartz-2008.pdf)**

    2008 年的一页短文，讨论从有标准答案的课程进入未知问题时的困惑。

- **[How Do I Get Started in Research? — Stanford Academic Advising](https://advising.stanford.edu/current-students/advising-student-handbook/start-research)**

    Stanford 的本科研究指导，介绍研究兴趣、教师交流与校内项目。

## 实验与评测

- **[A Recipe for Training Neural Networks — Karpathy](https://karpathy.github.io/2019/04/25/recipe/)**

    2019 年的训练经验文章，讨论数据检查、简单模型、拟合测试与训练排查。

- **[Deep Learning Tuning Playbook — Google Research](https://github.com/google-research/tuning_playbook)**

    深度学习调参手册，涵盖初始配置、实验组织和优化问题。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/sklearn.ico" alt="" loading="lazy"> scikit-learn：Common pitfalls and recommended practices](https://scikit-learn.org/stable/common_pitfalls.html)**

    通过代码对照解释数据泄漏、预处理不一致与随机性等常见问题。

- **[Task-Specific LLM Evals that Do & Don’t Work — Eugene Yan](https://eugeneyan.com/writing/evals/)**

    讨论面向具体 LLM 应用的评测对象、评价方法与实践经验。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/jupyter.svg" alt="" loading="lazy"> Jupyter](https://jupyter.org/)**

    Notebook 工具，将代码、分析文字、表格与图放在同一份文档中。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/rainbow.png" alt="" loading="lazy"> Rainbow CSV](https://marketplace.visualstudio.com/items?itemName=mechatroner.rainbow-csv)**

    VS Code 扩展，用颜色区分 CSV／TSV 各列，并检查列数。

## 写作、排版与汇报

- **[How to write a great research paper — Simon Peyton Jones](https://www.microsoft.com/en-us/research/academic-program/write-great-research-paper/)**

    研究论文写作讲座与幻灯片，讨论问题、贡献与文章结构。

- **[MLNLP Paper-Writing-Tips](https://github.com/MLNLP-World/Paper-Writing-Tips)**

    论文写作资料与检查清单，涉及格式、表达和投稿细节。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/overleaf.svg" alt="" loading="lazy"> Learn LaTeX in 30 minutes — Overleaf](https://www.overleaf.com/learn/latex/Learn_LaTeX_in_30_minutes)**

    Overleaf 的 LaTeX 入门教程，介绍文本、公式、图片与引用。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/markdown.svg" alt="" loading="lazy"> Markdown Guide：Basic Syntax](https://www.markdownguide.org/basic-syntax/)**

    Markdown 语法参考，包含标题、链接、列表、图片与代码块。

- **[How to give a great research talk — Simon Peyton Jones 等](https://www.microsoft.com/en-us/research/academic-program/give-great-research-talk/)**

    研究汇报讲座与幻灯片，讨论听众、信息组织与报告安排，也提供中文幻灯片。

- **[Fundamentals of Data Visualization — Claus O. Wilke](https://clauswilke.com/dataviz/)**

    数据可视化开放教材，讨论图表选择、配色与可读性。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/astradraw.png" alt="" loading="lazy"> AstraDraw](https://github.com/AstraDraw/astradraw)**

    协作白板与演示项目，用于组织图示和演示内容。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/latex.png" alt="" loading="lazy"> LaTeX Workshop](https://github.com/James-Yu/LaTeX-Workshop)**

    VS Code 的 LaTeX 编译、预览与引用补全扩展，配合本地 TeX 环境使用。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/spell.png" alt="" loading="lazy"> Code Spell Checker](https://marketplace.visualstudio.com/items?itemName=streetsidesoftware.code-spell-checker)**

    英文拼写检查扩展，支持笔记、README 与代码注释。
