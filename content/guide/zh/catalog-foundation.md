# 课程、教材与基础学习

基础课各有侧重：Crash Course 介绍领域全貌，3Blue1Brown 用图像解释数学，MIT 和 Stanford 的课程有系统的讲义与作业。

## 计算机与开发工具

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/crash.png" alt="" loading="lazy"> Crash Course Computer Science](https://thecrashcourse.com/topic/computerscience/)**

    英文科普视频，介绍二进制、CPU、程序、操作系统、文件系统与互联网，由 Carrie Anne Philbin 主持。 [官方介绍](https://thecrashcourse.com/courses/crash-course-computer-science-preview/)

    中文计算机自学指南，整理各领域的课程、教材与学习经验。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/missing.png" alt="" loading="lazy"> The Missing Semester of Your CS Education](https://missing.csail.mit.edu/)**

    开发工具课程，讲解 Shell、Git、调试等内容，配有视频和练习。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/git.ico" alt="" loading="lazy"> Pro Git 中文版](https://git-scm.com/book/zh/v2)**

    Git 在线教材，涵盖基本操作、历史记录、分支、远程仓库与协作。

## 数学

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/3b1b.svg" alt="" loading="lazy"> 3Blue1Brown：线性代数](https://www.3blue1brown.com/?topic=linear-algebra)**

    用几何动画解释向量、线性变换、矩阵乘法与特征向量。 [B 站入口](https://space.bilibili.com/88461692/)

    <figure class="resource-figure medium"><a href="https://www.3blue1brown.com/?topic=linear-algebra"><img src="../../../public/blog/guide/figures/uestc/intro/3b1b-vectors.jpg" alt="3Blue1Brown · 线性代数的本质" loading="lazy" width="367" height="206"></a><figcaption><a href="https://www.bilibili.com/video/BV1ys411472E/">B 站</a></figcaption></figure>

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/3b1b.svg" alt="" loading="lazy"> 3Blue1Brown：The Essence of Calculus](https://www.3blue1brown.com/lessons/essence-of-calculus/)**

    微积分视频与图文系列，从微小变化讲到导数、积分与链式法则。

    <figure class="resource-figure compact"><a href="https://www.3blue1brown.com/lessons/essence-of-calculus/"><img src="../../../public/blog/guide/figures/uestc/intro/3b1b-calculus.jpg" alt="微积分的本质" loading="lazy" width="367" height="205"></a><figcaption><a href="https://www.bilibili.com/video/BV1qW411N7FU/">B 站</a></figcaption></figure>

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/seeing.png" alt="" loading="lazy"> Seeing Theory — Brown University](https://seeing-theory.brown.edu/)**

    概率统计交互教程，展示分布、抽样与统计推断。

- **[MIT 18.06 Linear Algebra — Gilbert Strang](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)**

    Gilbert Strang 的线性代数课程，涵盖子空间、正交、特征值与 SVD，提供视频、讲义和作业。

    <figure class="resource-figure medium"><a href="https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/"><img src="../../../public/blog/guide/figures/uestc/intro/mit-1806.jpg" alt="MIT 18.06 · 线性代数" loading="lazy" width="480" height="360"></a><figcaption><a href="https://www.bilibili.com/video/BV1zx411g7gq/">B 站</a></figcaption></figure>

- **[Harvard Stat 110 — Joe Blitzstein](https://stat110.hsites.harvard.edu/)**

    Joe Blitzstein 的概率论课程，配套教材与练习，涵盖条件概率、期望和常见分布。

- **[Mathematics for Machine Learning](https://mml-book.github.io/)**

    开放教材，将矩阵分解、向量微积分、概率与优化放在机器学习背景下介绍。

    <figure class="resource-figure book"><a href="https://mml-book.github.io/"><img src="../../../public/blog/guide/figures/uestc/resources/mml.jpg" alt="Mathematics for Machine Learning" loading="lazy" width="180" height="261"></a></figure>

## 机器学习与深度学习

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/isl.png" alt="" loading="lazy"> An Introduction to Statistical Learning](https://www.statlearning.com/)**

## Python 与模型实现

- **[CS50’s Introduction to Programming with Python](https://cs50.harvard.edu/python/)**

    Python 入门课，从函数、条件和循环讲到异常、库、文件读写与测试，配有编程练习。

    <figure class="resource-figure medium"><a href="https://cs50.harvard.edu/python/"><img src="../../../public/blog/guide/figures/uestc/intro/cs50p.png" alt="CS50P · Python 入门" loading="lazy" width="378" height="225"></a></figure>

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/numpy.ico" alt="" loading="lazy"> NumPy: the absolute basics for beginners](https://numpy.org/doc/stable/user/absolute_beginners.html)**

    NumPy 官方入门教程，介绍数组、shape、索引、轴与广播。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/pytorch.webp" alt="" loading="lazy"> PyTorch：Learn the Basics](https://docs.pytorch.org/tutorials/beginner/basics/intro.html)**

    PyTorch 官方教程，包含数据加载、模型定义、自动求导、优化与模型保存。

- **[Neural Networks: Zero to Hero — Karpathy](https://karpathy.ai/zero-to-hero.html)**

    从 micrograd 自动求导引擎和字符语言模型开始，逐步实现神经网络、GPT 与 tokenizer。

    <figure class="resource-figure medium"><a href="https://karpathy.ai/zero-to-hero.html"><img src="../../../public/blog/guide/figures/uestc/intro/micrograd.jpg" alt="Neural Networks: Zero to Hero" loading="lazy" width="1280" height="720"></a><figcaption><a href="https://www.bilibili.com/video/BV1mqrTBvEaf/">B 站</a></figcaption></figure>

## 模型架构与图解

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/jay.jpg" alt="" loading="lazy"> The Illustrated Transformer — Jay Alammar](https://jalammar.github.io/illustrated-transformer/)**

    Transformer 架构图解，解释 token 表示、注意力与 encoder/decoder 的组成。

- **[The Annotated Transformer — Harvard NLP](https://github.com/harvardnlp/annotated-transformer)**

    带逐段注释的 Transformer 实现，将论文中的结构、公式与代码对应起来。

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/polo.png" alt="" loading="lazy"> Transformer Explainer — Polo Club](https://poloclub.github.io/transformer-explainer/)**

    Transformer 交互演示，展示输入经过模型并得到下一个 token 预测的计算过程。

- **[李宏毅：Self-Attention 与 Transformer](https://speech.ee.ntu.edu.tw/~hylee/ml/2021-spring.php)**

    机器学习课程中的注意力机制与 Transformer 专题。

    <figure class="resource-figure compact"><a href="https://speech.ee.ntu.edu.tw/~hylee/ml/2021-spring.php"><img src="../../../public/blog/guide/figures/uestc/resources/hongyi-attention.jpg" alt="李宏毅 · Self-Attention 与 Transformer" loading="lazy" width="368" height="206"></a><figcaption><a href="https://www.bilibili.com/video/BV1r8nMz4EAj/">B 站</a></figcaption></figure>

- **[<img class="resource-mark" src="../../../public/blog/guide/figures/uestc/resources/colah.ico" alt="" loading="lazy"> Understanding LSTM Networks — colah](https://colah.github.io/posts/2015-08-Understanding-LSTMs/)**

    LSTM 图解，通过状态传递与门控解释序列处理。

- **[科学空间：文章归档 — 苏剑林](https://kexue.fm/content.html)**

    技术文章归档，包含“Transformer 升级之路”“生成扩散模型漫谈”等系列。
